# Supplier Onboarding and Evaluation (SOP-PROC-003)

**Owner:** Supplier Management · **Version:** 1.4

## 1. Onboarding steps
A new supplier is created with status **PENDING** and can only receive POs after all steps
are complete and the status is set to **APPROVED**:

1. **Business justification** from the requesting buyer (why existing suppliers are not
   sufficient).
2. **Tax and legal data:** tax ID (EIN / VAT), registered address, W-9 or W-8BEN form.
3. **Bank details verification** via a call-back to a phone number from an independent source
   (fraud prevention). Bank detail changes later follow the same call-back rule.
4. **Sanctions and compliance screening** (denied-party lists, anti-bribery declaration).
5. **Quality questionnaire**; ISO 9001 certificate for production materials.
6. **Commercial terms:** payment terms (standard **NET30**; NET45/NET60 need Finance approval),
   Incoterms, minimum order quantities.

Target onboarding lead time: 10 business days.

## 2. Duplicate prevention
Before creating a supplier, the master-data team searches by **tax ID** and normalised name.
A supplier with the same tax ID must never be created twice (see SOP-MDM-001).

## 3. Performance evaluation
Suppliers are rated quarterly on a 1–5 scale (on-time delivery, quality, price, responsiveness).
- Rating **below 3.0**: improvement plan with the buyer.
- Rating below 2.5 for two consecutive quarters, or a serious compliance breach: status set to
  **BLOCKED**. Blocked suppliers cannot receive new POs; open POs are reviewed individually.

## 4. Re-approval
Approved suppliers are re-screened every 12 months (sanctions, certificates, bank details).
